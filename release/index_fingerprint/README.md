# Chunk-set fingerprint

Fingerprint of the chunk set indexed as Qdrant collection `geno_agent_pmc_oa_v1`.
Lets a reuser verify a rebuild of the retrieval substrate against the released
chunk set without redistributing any chunk text.

Generated by `scripts/corpus/compute_chunk_fingerprint.sh` on 2026-07-25 from
`all_chunks.jsonl.gz` (SHA-256 `da59cd55…89aa0354`, listed in `data/MANIFEST.tsv`).

## Recipe

```bash
zcat <chunk JSONL(s), file order LC_ALL=C sorted> \
  | jq -r '[.chunk_id,.pmcid]|@tsv' \
  | LC_ALL=C sort -u > pairs.sorted

cut -f1 pairs.sorted | sha256sum                       # chunk_id_fingerprint.txt
cut -f2 pairs.sorted | LC_ALL=C sort | uniq -c \
  | awk '{print $2"\t"$1}' > chunk_counts_by_pmcid.tsv
```

Two steps are load-bearing and a rebuild will not match without them:

- **`LC_ALL=C`** — locale-dependent collation orders the identifier list
  differently and therefore yields a different digest.
- **`sort -u`** — the digest is defined over the chunk *set*, matching what the
  collection holds, not over the raw record stream. `chunk_id` is a
  content-addressed UUID5, so a resumed build can re-emit a record an earlier
  pass already wrote; that record upserts onto the same point and must not be
  counted twice. The released build emitted 5,394 such duplicates.

## Why the PMCID row count is lower than `retained_pmcids.txt`

`retained_pmcids.txt` lists 2,254,388 articles that passed the genetics-relevance
filter. `chunk_counts_by_pmcid.tsv` lists 2,249,438. The 4,950-article difference
is articles for which no section reaches the 50-character minimum, so they
contribute no chunk. The manifest identifiers are a **strict subset** of
`retained_pmcids.txt` — verified: zero identifiers appear in the manifest that
are absent from the retained list.

## Independent corroboration

The 5,394-duplicate figure is not an artefact of this recomputation. The
contemporaneous build record `reports/qdrant_upload_stats_2026-05-13.json` — written
2026-05-13, the day the collection was uploaded — independently reports:

```
points_uploaded_by_script : 52,782,789
points_count              : 52,777,395
delta_uploaded_vs_points  : 5,394
delta_explanation         : "UUID5 chunk_id collisions when two articles produce
                             identical (pmcid, section_type, chunk_index,
                             blake2b(text)). Idempotent upsert keeps one."
```

Those are the same three numbers and the same mechanism derived independently here
in 2026-07 from the chunk file alone.

## History

An earlier `data/MANIFEST.tsv` row, `qdrant:geno_agent_pmc_oa_v1:fingerprint` =
`c6e53665…07f3d6e` (added 2026-05-13, commit `13b093d`), was removed in 2026-07.
It was hand-authored, no recipe for it existed anywhere in the repository, and 23
candidate derivations failed to reproduce it — so a reuser could not have verified
a rebuild against it. The digests in this directory replace it and are
reproducible in one command. The removed row remains recoverable from git history
(`git log -S c6e53665`), and the point count it carried is preserved in the build
record cited above.
