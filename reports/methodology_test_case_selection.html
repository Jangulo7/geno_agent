geno_agent — Test Case Selection Methodology

How the 75 test cases used across every evaluation cell (A–K + P + L + Q/R/S to come) were selected from the GA4GH Phenopacket Store. Designed for reproducibility, representativeness, and cross-cell comparability.
Canonical file data/test_cases/test_cases.jsonl sha256 4872afb6… Master plan ref §6 + §11.5 n 75 (stratified)

The three properties this pipeline must guarantee

1. Reproducibility. Anyone re-running the pipeline must obtain the same 75 cases in the same order with the same 50 candidate genes each.

2. Representativeness. The sample must cover the four target MONDO categories defined by the master plan with roughly equal weight (within 20 %).

3. Comparability. Every experimental cell must process exactly the same 75 cases so that pairwise comparisons (e.g. Cell D vs Cell K) are well-defined and statistically meaningful via paired-bootstrap CIs.

7.Why all 11+ evaluation cells are mutually comparable

Every evaluation cell reads from the same canonical file and writes per-case outputs under the same schema. This makes paired comparisons (D vs K, D vs rerank, etc.) mathematically well-defined.

What this enables

Paired statistics

For any two cells, top-1 can be compared on the same case under both pipelines. Paired-bootstrap CIs (1 000 resamples, seed=42) are correctly computed.

Per-MONDO consistency

Cell K's "immunological top-1 = 0.421" is on the same 19 cases as Cell D's "immunological top-1 = 0.474" — so D > K on that subset by exactly 1 case.

Per-case insight

"ADRA2A moved from D rank 50 → rerank rank 1" means the same Phenopacket got rank 50 in Cell D and rank 1 under rerank-inside-D — not a different ADRA2A patient.

9.Limitations worth flagging

Limit 1 — N=75 is modest

Bootstrap CIs are wide (± ~0.10 on top-1 around 0.5–0.7). A larger sample (~200) would tighten inferences but was outside compute budget.

Limit 2 — only 4 MONDO categories

The thesis claim covers developmental / immunological / metabolic / neurological. Oncology, infectious disease, cardiac, dermatological etc. are not represented.

Limit 3 — multi-category cases resolved deterministically

A case mapping to both developmental and metabolic is assigned to the higher-priority category per the script's tie-break. Recorded as deviation in master plan §10.

Limit 4 — PMC coverage is a fair-test requirement, not generalisation

Cases where the causal gene has < 5 PMC articles are excluded. Literature-RAG cannot be tested on undocumented genes by design.

Limit 5 — single causal gene per case

Real clinical cases sometimes have multiple plausible candidates. The binary top-1 target does not capture that complexity.

Limit 6 — no held-out validation split

With only 75 cases, we use the full set for every cell. There is no separate held-out subset for hyperparameter tuning. Hyperparameters were set from literature, not tuned on these cases.
