geno_agent — agentic multi-agent RAG for gene prioritization

A reproducibility-first retrieval pipeline over PubMed Central Open Access, validated end-to-end on a 100-article rare-disease sample. RTX 5090 / cu128 / Qdrant 1.14.1. Master's thesis (TFM), Universidad UAX.

100 articles fetched 1,625 chunks indexed 12 / 12 probes return relevant top-1 44 s wall-clock deterministic UUID5 chunk IDs

1What this demo proves

Phase 1A of geno_agent is the corpus-build substrate the four downstream agents (Query Planner, Retriever, Critic, Synthesizer) will retrieve from. This run shows the substrate is functional, fast on a single workstation, and deterministic by construction.

What this enables for the report. The pipeline is the infrastructure on which the agentic layer (Phase 2) and the test-case benchmark (Phase 1B) depend. With the substrate validated, the remaining work is well-scoped: scale this same pipeline up to the full 150 GB corpus per the master plan §7 tier-by-tier strategy, then layer the four agents on top.

2Architecture

Five stages, each with its own script and reproducibility contract. Inputs are pinned and SHA-256-hashed; chunk IDs are deterministic UUID5; the dense+BM25 hybrid index is native to Qdrant; retrieval is reciprocal rank fusion at query time.

4Embedding throughput on RTX 5090

The Blackwell GPU (cu128 nightly torch) runs NeuML/pubmedbert-base-embeddings at 351 chunks/s. For the production 3-million-chunk corpus this projects to roughly 140 minutes of pure GPU encoding — well inside the master-plan §7 estimate of 8–16 hours per tier (which budgets I/O, batching warm-up, and per-tier model reload).

5Hybrid retrieval — 12 probes, 3 modes

Each probe is run dense (SentenceTransformer.encode), BM25 (SparseTextEmbedding.query_embed — TF only on the query side, IDF applied server-side via Modifier.IDF), and hybrid (Qdrant FusionQuery(Fusion.RRF) over both prefetches). All twelve probes return relevant top-1 chunks across all three modes.

7Reproduce this run yourself

From the project root, with Docker running:

source /home/hana77/pytorch-env/bin/activate
docker compose up -d                                 # qdrant_geno_agent on :6533/:6534

python scripts/ontology/12_verify_ontologies.py      # one-time
python scripts/indexing/10_create_qdrant_index.py    # one-time

bash scripts/demo/run_pipeline.sh                    # ~44 s end-to-end
python scripts/demo/collect_stats.py                 # → pipeline_stats.json
python scripts/demo/make_visualizations.py           # → reports/images/*.png
