4Recommended resumption strategy

Recommendation: parallelize Track A (machine) with Track C (engineering).
  • Today / tomorrow: write the 1-hour scripts/corpus/01_download_pmc_oa.sh. Kick off oa_comm sync tonight inside tmux.
  • Next 5–7 days: while the GPU runs unattended on the corpus, develop the agent layer (Track C) against the existing 1,625-chunk demo index. The retrieval semantics scale identically; agent prompts and grading are the highest-uncertainty work.
  • Day 7–8: Track A finishes → Track B (Phase 1B) on the populated production index. ~1–2 days engineering.
  • Day 9+: wire the agents (built day 2–6) to the production corpus. Run quantitative evaluation (precision@K, recall@K, nDCG vs Exomiser baseline).
