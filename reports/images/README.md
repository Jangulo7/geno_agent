# images/ — historical Phase-1A demo artifacts (NOT manuscript figures)

These files are **research/demo artifacts from the Phase-1A pipeline demo**
(May 2026, a 100-article / 1,625-chunk demonstration index). **None are used by
the P1 or P2 manuscripts** — the papers' figures live in `reports/figures/` and
are generated by `scripts/manuscript/`. Kept here for historical/provenance
reference only; the numbers reflect the demo run, not the final n=1,047 research.

| File | Depicts | Generator | Status |
|---|---|---|---|
| `pipeline_throughput.png` | per-step pipeline timing (100 articles) | `scripts/demo/make_visualizations.py` | historical demo |
| `section_distribution.png` | chunks per JATS section (1,625 chunks) | `scripts/demo/make_visualizations.py` | historical demo |
| `embedding_throughput.png` | PubMedBERT embed throughput (RTX 5090) | `scripts/demo/make_visualizations.py` | historical demo |
| `retrieval_modes.png` | dense/BM25/hybrid probe queries | `scripts/demo/make_visualizations.py` | historical demo |
| `terminal_screenshot.png` | `11_validate_index.py` output (demo index) | `scripts/demo/make_visualizations.py` | historical demo |
| `architecture.svg` | Phase-1A corpus/ingest pipeline | hand-authored SVG | superseded by `figures/fig2_architecture.png` |
| `agent_architecture.svg` | agentic-workflow architecture (conceptual) | hand-authored SVG | **current** — embedded by `reports/agent_architecture.md` |

To regenerate the demo PNGs: `python scripts/demo/make_visualizations.py`
(reads `reports/pipeline_stats.json`).
