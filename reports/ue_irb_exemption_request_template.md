# UE IRB exemption confirmation — request template (bilingual ES/EN)

**Purpose:** Request a publication-specific confirmation letter from
the Universidad Europea (UE) ethics secretariat / Comité de Ética de
la Investigación, extending the existing doctoral-research exemption
to the Genome Medicine submission.

**Background:** The doctoral researcher already holds a UE exemption
letter confirming that the underlying research does not require ethics-
committee review (no human experimentation; secondary analysis of
publicly-available, de-identified, already-published benchmark data
from the GA4GH Phenopacket Store). Genome Medicine reviewers and the
TRIPOD-LLM reporting guideline (Item 13) require an explicit
publication-specific statement; some journals accept the original
exemption letter, but the cleanest path is a short signed
confirmation referencing this specific manuscript.

**How to use this template:**
1. Email the request (Section A) to the UE ethics secretariat with
   the existing exemption letter attached, citing its reference number.
2. Provide the draft confirmation letter (Section B) for the
   secretariat / committee chair to sign, on UE letterhead, dated.
3. Once received, scan it as a PDF and attach as **Supplementary
   File 2** to the Genome Medicine submission, and update
   `manuscript_q1_draft.md` §Declarations §Ethics with the document
   reference (replacing the current placeholder flag).
