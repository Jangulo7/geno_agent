# reports/

This directory holds the **rendered artifacts** of the study that are intended to be
inspectable from the repository:

- `figures/` — result figures (CONSORT flow, per-MONDO top-1, faithfulness vs.
  correctness, LLM-family ablation, recency).
- `tables/` — result tables (overall accuracy, fair-comparison paired deltas,
  multiplicity correction, LLM ablation, wall-clock/cost).
- `images/` — architecture and throughput diagrams.
- `run_logs/` and the `*_stats*.json` files — pipeline execution logs and build
  statistics.

**Manuscripts and intermediate research write-ups are intentionally not tracked
here.** The methodology document, execution plans, result narratives, compliance
checklists, and the P1/P2 manuscript drafts are maintained as **local working
documents and kept private until publication**; they remain on the author's machine
for records and supervisory review.

The published, citable versions of the methodology, benchmark, and system are
available through the project's Figshare deposits — see *Data and software
availability* in the top-level [`README.md`](../README.md).
