# Archived APA-style manuscript variants

These are **APA author-year** renderings of the GenoAgent (P2) manuscript and its
Methods section. They were previously hand-maintained in parallel with the
Vancouver/numbered canon, which caused drift (every content edit had to be mirrored
in two files).

**Canonical sources** (edit these) live in `reports/`:

- `reports/manuscript_q1_draft.md` — GenoAgent paper, Vancouver/numbered
  (Genome Medicine house style).
- `reports/manuscript_methods_draft.md` — its Methods section.

The APA variants here are frozen. If a fallback journal requires APA, regenerate it
from the canonical source at submission time (e.g. `pandoc` with an APA CSL file or
a reference manager) rather than reviving hand-maintenance.
